Lifecycle of a transformer call

An input prompt enters the model as text, is tokenised into a stream of integer IDs, embedded into vectors, run through attention layers, and finally decoded one token at a time until a stop signal.

const tokens = tokenizer.encode("hola mundo"); const output = await model.generate(tokens);
