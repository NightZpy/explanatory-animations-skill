How a transformer answers a prompt

Read top-to-bottom. Scroll at your own pace. The cursor highlights each step in turn.

01

Input text

string

The user sends a prompt as plain text.

↓ tokenize
02

Tokenizer

BPE / SentencePiece

Splits the text into subword tokens, mapping each to an integer ID.

↓ embed + pos
03

Token + positional embeddings

[N, d_model]

Each token becomes a learned vector; positional info is added in.

↓ attention × N
04

Attention + FFN stack

N transformer blocks

Each block lets every token look at every other and refine its representation.

↓ project + sample
05

LM head + sampling

→ next token

Final vector projects to vocabulary scores; one token is sampled.

This is the browser-native shape.
Cards stack vertically and the page scrolls — comfortable to read, easy to skim back. Good for tutorials, docs, study material.
